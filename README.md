# Água Invisível

Site educativo sobre **pegada hídrica cotidiana e digital**: calculadora em tempo real, simulador de comandos de IA, comparador de alimentos, gráficos e quiz.

Stack: **Next.js (App Router)** · **Tailwind CSS v4**

## Começar

```bash
npm install
npm run dev
```

Alimentos e cálculos usam `src/lib/constants.ts`. Não há banco nem autenticação.

## Scripts

| Comando | Uso |
| --- | --- |
| `npm run dev` | Servidor local |
| `npm run build` | Build de produção |

## Aviso

Os litros são **estimativas educativas** (Water Footprint Network, SNIS e faixas publicadas sobre resfriamento de data centers), não medições de laboratório.
